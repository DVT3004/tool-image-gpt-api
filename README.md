# Flow Multi-Account Image Tool

App desktop tạo / sửa ảnh qua Google Labs **Flow** (Nano Banana), đa tài khoản + đa luồng.

Mã nguồn nằm trong **[`flow-tool/`](flow-tool/)** — xem [flow-tool/README.md](flow-tool/README.md).

## Chạy nhanh

```bash
pip install -r requirements.txt
playwright install chromium
cd flow-tool
python gui_modern.py        # hoặc bấm run_gui_modern.bat
```
